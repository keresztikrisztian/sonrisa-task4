# Sonrisa Task 4 – Event Alert System

## Overview

This repository contains an AI-assisted implementation of an extensible event alerting system based on an intentionally ambiguous product brief.

The system is intended to allow users to configure alerts for important events, such as breaking news, market movements, and natural disasters.

The initial requirements include:
- User-configurable alert rules
- Email and Slack notification support
- Extensibility for additional notification channels
- An administration interface

## Technology Stack

- **Backend:** ASP.NET Core Web API (C#)
- **Frontend:** Angular (TypeScript)
- **Version Control:** Git / GitHub
- **AI-assisted Development:** AI agents for planning, implementation, testing, and review

Database technology, event sources, and other infrastructure decisions will be documented during the design phase.

## Project Structure

- `backend/` – ASP.NET Core backend
- `frontend/` – Angular frontend
- `docs/` – Plans, architectural decisions, and validation results
- `ai-history/` – AI prompts and relevant outputs

## Development Approach

The project follows an iterative, AI-assisted development process:

1. Analyze the ambiguous requirements.
2. Define assumptions and MVP scope.
3. Design the system architecture.
4. Implement features with AI assistance.
5. Critically review and validate generated code.
6. Document decisions, corrections, and limitations.

## Current Status

The MVP now includes the ASP.NET Core API and an Angular interface for demo identity selection, user alert-rule management, admin event submission, and notification delivery monitoring. Demo identity headers are for local demonstrations only and are not production authentication.

## Evaluation Focus

The primary objective is to demonstrate the development process, including:

- Problem analysis and requirement clarification
- Technical decision-making
- Effective use of AI agents
- Critical evaluation of AI-generated outputs
- Testing and validation
- Transparent documentation of limitations
